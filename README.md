# AWS Security Risk Assessment — NIST CSF 2.0

## Project Overview

This project documents a hypothetical cybersecurity risk assessment for Northstar Workflow, Inc., a fictional small software-as-a-service (SaaS) company operating in an assumed AWS cloud environment.

The assessment uses the NIST Cybersecurity Framework (CSF) 2.0 to organize cybersecurity outcomes and relevant controls from NIST Special Publication 800-53 to support control assessment and risk analysis.

## Objectives

- Define the organization's business context and assessment scope.
- Identify cybersecurity risks and potential business impacts.
- Map relevant security controls to recognized NIST guidance.
- Document assessment evidence, findings, and control gaps.
- Recommend prioritized remediation actions.
- Communicate risk and recommendations in an executive summary.

## Project Status

**In progress.** The business scenario, assessment scope, hypothetical system description, preliminary risk register, control matrix, and preliminary assessment findings have been documented.

Evidence collection and validation, remediation planning, and executive reporting remain outstanding.

Risk ratings and proposed controls are preliminary and have not been validated against a live AWS environment.
